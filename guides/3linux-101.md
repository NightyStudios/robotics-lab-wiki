# Linux

Linux — ядро операционной системы. Оно управляет драйверами, сигналами, выделяет память и делает очень много полезного.

Вместе с пакетом команд GNU Coreutils GNU/Linux становится очень мощным инструментом для разработки и запуска приложений.

На GNU/Linux построены _дистрибутивы_, то есть версии этой замечательной ОС, созданные для повседневного использования.

Есть дружелюбные для пользователя Debian, Mint и Fedora. Есть кастомизируемые Arch и Gentoo. Есть даже NixOS, в которой состояние ОС задается в конфигурационном файле (условно `приложения.chrome.включить = истина;`).

И наконец, на GNU/Linux работает большинство серверов, так что работать с этой системой нужно научиться каждому.

# Дерево файловой системы

ФС в Linux представляет собой иерархичную структуру, которая описывает, как файлы и папки (директории) лежат относительно друг друга.
Это дерево выглядит примерно вот так:

```bash
/
├── bin -> usr/bin    # Основные команды
├── boot/             # Загрузчик и ядро
├── dev/              # Устройства
├── etc/              # Системные конфигурации
├── home/             # Домашние каталоги
│   └── user/
│       ├── Documents/
│       ├── Downloads/
│       └── .config/  # Настройки пользователя
├── lib -> usr/lib    # Системные библиотеки
├── lib64/            # 64-битные библиотеки/загрузчик
├── media/            # Съёмные носители
├── mnt/              # Ручное монтирование
├── opt/              # Дополнительное ПО
├── proc/             # Процессы и информация о ядре
├── root/             # Домашний каталог root
├── run/              # Данные запущенных служб
├── sbin -> usr/bin   # Системные утилиты
├── srv/              # Данные серверов
├── sys/              # Интерфейс к устройствам и ядру
├── tmp/              # Временные файлы
├── usr/              # Программы и ресурсы
│   ├── bin/          # Исполняемые файлы
│   ├── lib/          # Библиотеки
│   ├── local/        # Локально установленное ПО
│   └── share/        # Общие ресурсы
└── var/              # Изменяемые данные
    ├── cache/        # Кэш
    ├── lib/          # Состояние приложений
    └── log/          # Журналы
```

Все директории отсчитываются с `/`. Слеш — _**корень**_ нашего дерева. Есть еще одно полезное обозначение — `*`. Оно буквально значит "всё". Например, `/*` — все, что лежит в `/`, а `/tmp/*` — все, что лежит в `tmp` (это системная директория для временных файлов, которые стираются после перезапуска).

Давайте рассмотрим самые частые и полезные папки, которые надо знать. `/home/user` — ваша домашняя папка, вы можете делать в нее все, что вам заблагорассудится. Она же обозначается значком _тильды_ — `~`. Помимо нее вам могут понадобиться следующие директории:

- `/dev` — директория с устройствами, которые вы, например, подключаете по USB.
- `/bin` — директория с бинарниками (исполняемыми файлами).
- `/home/user/.config` — директория внутри домашней, в которую обычно складируются конфиги. Обратите внимание: имя пользователя у вас может быть любым, а не только `user`. Есть еще один момент: если в начале директории стоит точка, то она будет считаться скрытой. О том, на что это влияет, мы поговорим позже.

# Команды в терминале

В Linux многие базовые команды, например `ls` и `cp`, входят в набор GNU Coreutils. В этом разделе мы посмотрим и на другие команды, которые пригодятся в терминале. Если вы видели, как в сериалах хакеры очень пафосно набирают команды в терминале, то поздравляю вас, сейчас вы сможете побыть таким вот хакером.

## man - мануал

Итак, самая первая и полезная команда — `man`. `man` — сокращение от manual. Если набрать `man` и название команды, то можно получить инструкцию по использованию этой самой команды. Например:

```bash
temmie@MacBook-Air-Max robotics-lab % man cat
```

Эта команда выведет вот это:

```man
CAT(1)                                   General Commands Manual                                  CAT(1)

NAME
     cat – concatenate and print files

SYNOPSIS
     cat [-belnstuv] [file ...]

DESCRIPTION
     The cat utility reads files sequentially, writing them to the standard output.  The file operands
     are processed in command-line order.  If file is a single dash (‘-’) or absent, cat reads from the
     standard input.  If file is a Unix domain socket, cat connects to it and then reads it until EOF.
     This complements the Unix domain binding capability available in inetd(8).
```

> [!NOTE] Если вы хотите попробовать сами, то вам пригодятся команды управления пейджером. Именно в этом режиме открывается `man`. Итак, чтобы выйти, на английской раскладке нажмите на <kbd>q</kbd>. Пролистывать можно как стрелочками, так и мышью или тачпадом. Наконец, для того, чтобы найти какое-то слово, нажмите на слеш (<kbd>/</kbd>) и начните вводить искомое слово. Чтобы перепрыгнуть на следующее вхождение, нажимайте <kbd>n</kbd>.

Вы наверняка заметили, что перед набранной командой есть еще какие-то символы. Это настройки шелла (shell) — оболочки среды. `temmie` — моё имя пользователя, `MacBook-Air-Max` — имя машины в локальной сети, а собака — разделительный символ. `robotics-lab` — просто директория, в которой я сейчас нахожусь.

Наконец, знак процента означает конец служебной информации. Вместо него в `bash` может находиться, скажем, знак&nbsp;доллара&nbsp;`$`.

## sudo - права администратора

Иногда, когда вы пытаетесь запустить команду, вам может выбросить ошибку `Permission denied`. Это значит, что у вас недостаточно прав. А у кого же есть эти права? У пользователя `root`. Поэтому мы можем вежливо попросить систему исполнить нашу команду от его имени через `sudo`:

```bash
$ sudo command -arg1 -arg2 ...
```

Если `sudo` запросит пароль, по умолчанию введите пароль своей учётной записи. Символы при вводе могут не отображаться, это абсолютно нормально.

## pwd - текущая директория

`pwd` означает "print working directory". Если ввести эту команду, то она выведет полный или _абсолютный_ путь к текущей директории. Например:

```bash
$ pwd
/Users/temmie/coding/robotics-lab
```

> [!NOTE] Обратите внимание: у меня рабочая система — macOS, поэтому иерархия папок немного другая.

## ls - просмотр файлов в папке

`ls` помогает посмотреть, какие файлы есть в текущей директории. Обычный запуск команды покажет файлы и папки в рабочей директории (см. `pwd`):

```bash
$ ls
67.txt     guides     my-project
```

При этом у `ls` есть полезные _аргументы_, которые надо указывать через пробел с дефисом. Аргумент `-a` значит "all", то есть показывает ВСЕ файлы и папки, даже скрытые (с точкой в начале):

```bash
$ ls -a
.            ..           .secret-file 67.txt       guides       my-project
```

Точка (`.`) — способ обращения к текущей директории, две точки (`..`) — способ обращения к родительской директории (уровнем выше).

Есть еще два аргумента, которые идут в паре: `-lh` или можно раздельно `-l -h`. `-l` отображает файлы в качестве списка со служебной информацией в человекочитаемом формате размеров (этим занимается `-h`):

```bash
$ ls -lh
total 32
-rw-r--r--@ 1 temmie  staff    17B Nov 12 10:51 67.txt
drwxr-xr-x@ 4 temmie  staff   128B Nov 12 11:18 guides
-rw-r--r--@ 1 temmie  staff    11K Nov 12 11:24 linux-101.md
drwxr-xr-x@ 5 temmie  staff   160B Nov 12 11:08 my-project
```

Сравните с выводом, если я опущу флаг `-h`:

```bash
$ ls -l
total 32
-rw-r--r--@ 1 temmie  staff     17 Nov 12 10:51 67.txt
drwxr-xr-x@ 4 temmie  staff    128 Nov 12 11:18 guides
-rw-r--r--@ 1 temmie  staff  10839 Nov 12 11:24 linux-101.md
drwxr-xr-x@ 5 temmie  staff    160 Nov 12 11:08 my-project
```

Наконец, флаги можно комбинировать вместе или по отдельности:

```bash
$ ls -l -a -h

ИЛИ

$ ls -lah

total 32
drwxr-xr-x@  7 temmie  staff   224B Nov 12 11:22 .
drwxr-xr-x  26 temmie  staff   832B Oct 21 12:29 ..
-rw-r--r--@  1 temmie  staff     0B Nov 12 11:18 .secret-file
-rw-r--r--@  1 temmie  staff    17B Nov 12 10:51 67.txt
drwxr-xr-x@  4 temmie  staff   128B Nov 12 11:18 guides
-rw-r--r--@  1 temmie  staff    12K Nov 12 11:30 linux-101.md
drwxr-xr-x@  5 temmie  staff   160B Nov 12 11:08 my-project
```

## cat - прочитать файл

`cat` — не кот, как может показаться на первый взгляд. Это сокращение от слова concatenate — конкатенировать, то есть склеивать строки. Командой `cat` можно прочитать содержимое файла и вывести его в `stdout` (стандартный выход), то есть терминал. Например, у нас есть файл `67.txt`, в котором записано две строки:

```txt
Hello World!
67!
```

Прочитаем его через `cat 67.txt` и получим вывод в терминал:

```bash
$ cat 67.txt
Hello World!
67!
```

## less - пейджер

Иногда файл очень большой и выводить его полностью неудобно. Тогда пригодится `less` — команда, которая создает пейджер, подобный тому, который вы видели в `man`. Команды управления, кстати, те же.
На файлике `67.txt` команда `less` выведет:

```bash
$ less 67.txt

Hello World!
67!
67.txt (END)
```

Для выхода нажмите <kbd>q</kbd>.

## rm - удалить

Команда `rm` означает remove и помогает удалять файлы и папки. Чтобы удалить файл или файлы, просто пишете `rm file1 file2`, и команда удаляет эти самые файлы. Чтобы удалить папку, нужно добавить флаг `-r` (рекурсивно): `rm -r some_folder`. Есть еще один флаг: `-f`, он подавляет сообщения об ошибках.

> [!NOTE] На просторах интернета вам могут встретиться мемы, где новичкам советуют запустить команду якобы для "удаления французского языка". Так вот, **НИ В КОЕМ СЛУЧАЕ НЕЛЬЗЯ ЗАПУСКАТЬ ЭТУ КОМАНДУ!!!** Выглядит она вот так: `sudo rm -fr /* --no-preserve-root`. Как вы можете догадаться, она удаляет ВООБЩЕ ВСЕ ФАЙЛЫ И ДИРЕКТОРИИ на вашем компьютере, так что будьте осторожны :D

## cp и mv - копирование и перемещение

Вместе с удалением файлов и директорий их можно перемещать, копировать и переименовывать.
В этом нам помогают команды `cp` и `mv`. Они значат copy и move соответственно. Для перемещения файла синтаксис команды следующий: `mv file1 file2 file3 ... dest`, где dest значит destination, т. е. место назначения. Есть у `mv` еще одна функция — переименование файлов или директорий. Синтаксис следующий: `mv old_file_name new_file_name`. Для перемещения директории используем ту же команду — `mv directory_name dest`. С `cp` аналогично, `cp old_file_name new_file_name` создает файл `new_file_name` с содержанием, идентичным `old_file_name`. По аналогии `cp file1 file2 file3 ... dest` копирует файлы в место назначения, а флаг `-r` позволяет работать с директориями.

## cd - переход в папку

`cd` обозначает change directory. Использование у нее простое: `cd dest`, где `dest` — место назначения. Причем есть два варианта путей: _**относительный**_ и _**абсолютный**_. Если мы корнем примем `.` (т. е. текущую директорию), то мы получим _относительный_ путь. Например, если мы находимся по адресу `/Users/temmie/coding/robotics-lab` и хотим _относительно_ перейти в директорию `my-project`, то ее адрес в нашей системе отсчета будет `./my-project` или просто `my-project`.

Помимо этого есть _абсолютный_ путь, его мы отсчитываем от корня (/). Так что наш путь будет выглядеть следующим образом: `/Users/temmie/coding/robotics-lab/my-project`. Напоминаю, что у меня macOS, поэтому структура файлов немного другая.

## mkdir - создать папку

Команда `mkdir` позволяет создать директорию. Причем для того чтобы создать вложенную директорию (например, Книги/Проза/Пушкин/капитанская_дочка), есть флаг `-p`. Например:

```bash
$ ls
67.txt     guides     my-project

$ mkdir -p test/inner_test

$ ls
67.txt     guides     my-project test

$ cd test

$ ls
inner_test
```

## take - создать директорию и перейти

Если у вас установлен Oh My Zsh, команда `take` позволяет создать директорию и сразу в неё перейти:

```bash
$ pwd
/Users/temmie/coding/robotics-lab

$ take test

$ pwd
/Users/temmie/coding/robotics-lab/test
```

В обычном Bash то же самое можно сделать командой `mkdir -p test && cd test`.

# Переменные среды и конфигурации

## ENV

Linux славится своей кастомизируемостью. Поэтому есть разные способы настроить систему под ваш вкус. Есть полезная штука — переменные среды. Это как бы глобальные переменные, подобные таковым в Python. Они начинаются со знака доллара `$` и позволяют удобно хранить информацию, доступную по всей системе. Прочитать переменную можно через `echo`. Например:

```bash
$ echo $SHELL
/bin/zsh
```

У вас может отображаться и другая оболочка, например `/bin/bash`.

Задавать переменные можно командой `export` с таким синтаксисом: `export NAME=value`.
Например, зададим переменную TEST со значением test и выведем её:

```bash
$ export TEST=test

$ echo $TEST
test
```

Важный момент. Если открыть новый независимый сеанс терминала, заданная в прошлом сеансе переменная `TEST` сама там не появится. А команда `exec "$SHELL"` передаст экспортированные переменные новой оболочке. Чтобы `TEST` появлялась в каждом новом сеансе, добавьте `export TEST=test` в файл конфигурации оболочки.

# .bashrc

Файл конфигурации называется у вас ~/.bashrc или ~/.zshrc (в зависимости от вашего окружения).
В нем помимо прочего можно задавать `export` в знакомом вам синтаксисе и `alias`, который позволяет вам создавать собственные команды. Например, вы хотите, чтобы системный `python3` открывался как `py`. Синтаксис у команды следующий:

```.bashrc
alias py='python3'
```

# Менеджеры пакетов

У каждого дистрибутива есть менеджер пакетов - специальная программа, которая управляет другими пакетами: просчитывает зависимости, скачивает их и управляет ими. В Docker, который мы вам дали используется система Ubuntu. В ней (а еще в ее родителе Debian и сестре Mint) используется менеджер пакетов `apt`.
Вам понадобится всего несколько команд, вот собственно они:

- `apt update` - обновить списки `apt` (это нужно регулярно делать, чтобы не пропустить новые версии пакетов)
- `apt install package` - установить пакет (замените package на название пакета, который хотите поставить)
- `apt upgrade` - обновить установленные пакеты
- `apt remove package` - удалить пакет

# Полезные команды

Все эти пакеты вам нужно будет установить через `apt install`. Если что-то не работает - гуглите название и читаете инструкцию

## zoxide

`zoxide` запоминает директории в которые вы переходите с помощью команды `z` (работает эквивалентно `cd`) и позволяет прыгать между ними. Допустим вы ранее заходили в директорию `/home/user/folder` и в `/home/admin/projects`. Тогда находясь в `/home/user/folder` вы можете сразу прыгнуть в `/home/admin/projects` просто набрав `z projects`:

```bash
$ pwd
/home/user/folder

$ z projects

$ pwd
/home/admin/projects
```

> [!NOTE] После установки через `curl` или `apt` вам нужно будет добавить строку `eval "$(zoxide init bash/zsh)"` в `.bashrc/.zshrc` соответственно. После этого перезапустите оболочку через `exec $SHELL` и сможете прыгать по директориям через `z`.

## micro

Если `nano` показался вам неудобным, то можете установить `micro` - он более дружелюбен для пользователя и в нем работают стандартные сочетания клавиш: <kbd>Ctrl</kbd> + <kbd>S</kbd> для сохранения, <kbd>Ctrl</kbd> + <kbd>C</kbd> для копирования и пр. Чтобы выйти, нажмите <kbd>Ctrl</kbd> + <kbd>Q</kbd>.

## bat

Согласно описанию на официальном GitHub, `bat` - это `cat`, только с крыльями. Чтобы его использовать после установки лучше в `.bashrc` добавить строчку `alias bat='batcat'`, так как название пакета `bat` конфликтует с каким-то другим пакетом, а прописанная конфигурация позволяет это перезаписать.

## fzf

`fzf` - инструмент для т.н. fuzzy-поиска (т.е. неточного поиска). После его установки закиньте в `.bashrc/.zshrc` строчку `source <(fzf --bash/--zsh)` и тогда находясь в терминале по нажатию <kbd>Ctrl</kbd> + <kbd>R</kbd> вам откроется список введенных до этого команд вместе со строкой поиска.
