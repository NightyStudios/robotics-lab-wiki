## Переменные

Проще всего представить **переменную** в Python как коробочку, в которую можно положить значение и которую можно подписать. Обращаемся к переменной по имени и получаем значение, которое сейчас в ней лежит. При этом присваивать переменной новое значение можно сколько угодно раз.

Посмотрим на синтаксис:

```python
a = 10
b = 20
c = a + b * 2
print(c)  # 50

c = 10
print(c)  # 10
```

Знак `=` присваивает переменной слева значение выражения справа. Сначала мы кладём в `c` результат вычисления `a + b * 2`, после чего присваиваем ей новое значение `10`.

Можно присвоить значения сразу нескольким переменным. Здесь первая `20` попадает в `a`, а вторая — в `b`.

```python
a, b = 20, 20
print(a + b * 2)  # 60
```

> [!NOTE] Что такое print()
> `print()` — встроенная функция Python, которая выводит в консоль то, что вы передаёте ей в скобках. Можно передать готовое значение, имя переменной или выражение. В последнем случае Python сначала вычислит его, а затем выведет результат.

## Типы данных

У каждого значения в Python есть **тип**, от него зависит, какие операции с этим значением можно выполнять. Например, число можно поделить на другое число, а строку поделить на число нельзя. В одну и ту же переменную можно сначала положить число, а потом строку.

Начнём с четырёх базовых типов:

| Тип     | Что хранит               | Пример             |
| ------- | ------------------------ | ------------------ |
| `int`   | Целое число              | `10`               |
| `float` | Число с плавающей точкой | `10.1`             |
| `str`   | Строка                   | `"example"`        |
| `bool`  | Логическое значение      | `True` или `False` |

Посмотрим, как один и тот же знак `+` работает с разными типами. Если сложить `int` и `float`, получим число типа `float`.

```python
a = 10    # int
b = 10.1  # float
c = a + b
print(c)  # 20.1
```

Если сложить две строки, Python склеит их в одну. Строки можно записывать в одинарных или двойных кавычках. Даже один символ в кавычках, например `'T'`, имеет тип `str`.

```python
a = "example"
b = 'T'
c = a + b
print(c)  # exampleT
```

А что будет, если попытаться сложить число и строку? — Python выдаст ошибку `TypeError`. Сначала нужно решить, какой результат мы хотим получить:
* Чтобы склеить значения в одну строку, передадим число в `str()`;
* Чтобы сложить два числа, переведём строку в целое число через `int()`. Для этого в строке должна быть запись целого числа. Например, `"20"` подходит, а `"example"` вызовет ошибку `ValueError`.

```python
a = 10
b = "example"

print(str(a) + b)     # 10example
print(a + int("20"))  # 30

# print(a + b)       # TypeError
# print(a + int(b))  # ValueError
```

## Списки и словари

До сих пор мы клали в переменную по одному числу или строке. А что, если нам нужно хранить имена сразу двух камер? Можно завести две переменные, а можно собрать оба имени в **список**.

Список записываем в квадратных скобках, а элементы отделяем запятыми. Чтобы получить конкретный элемент, указываем его номер в квадратных скобках после имени списка. Этот номер называется *индексом*. В Python, как и в других языках, отсчёт начинается с нуля, поэтому первая камера находится под индексом `0`, а вторая — под индексом `1`.

```python
cameras = ["top", "front"]
print(cameras[0])  # top
print(cameras[1])  # front
```

Теперь представим, что хотим хранить вместе тип камеры и частоту кадров. Можно положить их в список, но тогда придётся помнить, на какой позиции лежит каждая настройка. Если у настройки уже есть имя, удобнее взять **словарь**.

Словарь хранит данные парами формата ``ключ: значение``, записываем его в фигурных скобках. Чтобы узнать частоту кадров, обращаемся к словарю по созданному нами ключу `"fps"`.

```python
camera1 = {"type": "front", "fps": 30}
print(camera1["fps"])  # 30

camera1["fps"] = 25
print(camera1["fps"])  # 25
```

Обратите внимание, как мы поменяли частоту: слева от `=` указали, какое значение в словаре хотим заменить, а справа написали новое.

Теперь добавим вторую камеру и соберём оба словаря в один список `cameras`.

```python
camera2 = {"type": "top", "fps": 30}
cameras = [camera1, camera2]

print(cameras[0]["type"])  # front
print(cameras[1]["fps"])   # 30
```

В записи `cameras[0]["type"]` сначала берём первый элемент списка по индексу `0`. Получаем словарь `camera1`, а уже из него берём значение по ключу `"type"`.

## Логические операции

Помните тип `bool` из таблицы? У него всего два значения — `True` и `False`. Одно из них мы получаем, когда сравниваем два значения. Например, если нужно проверить, что камера выдаёт хотя бы 30 кадров в секунду, сравним её частоту с числом `30`.

```python
fps = 25

print(fps == 30)  # False
print(fps != 30)  # True
print(fps > 30)   # False
print(fps < 30)   # True
print(fps >= 30)  # False
print(fps <= 30)  # True
```

`==` проверяет равенство, а `!=` — неравенство. Знаки `>` и `<` означают «больше» и «меньше», а `>=` и `<=` добавляют к сравнению «или равно».

А что, если одной проверки мало? Допустим, нам нужно узнать, что камера подключена и её частота не ниже 30 кадров в секунду. Для этого можно соединить проверки через `and`. Ещё есть `or`, когда достаточно одной из проверок, и `not`, когда нужно получить обратное значение.

```python
camera_type = "top"
camera_connected = True
fps = 25

print(camera_connected and fps >= 30)  # False
print(camera_type == "front" or camera_type == "top")  # True
print(not camera_connected)  # False
```

Если допустимые типы камер уже лежат в списке, можно проверить, есть ли среди них нужный. Для этого используем `in`. А `not in` проверяет, что элемента в списке нет.

```python
camera_types = ["front", "top"]

print("top" in camera_types)       # True
print("side" not in camera_types)  # True
```

А как обозначить, что мы ещё не выбрали камеру? Для таких случаев есть `None` — специальное значение, которым можно обозначить отсутствие данных. Чтобы проверить, что в переменной именно `None`, пишем `is None`.

```python
camera = None
print(camera is None)  # True

camera = {"type": "top", "fps": 30}
print(camera is not None)  # True
```

`is` проверяет, ссылаются ли выражения слева и справа на один и тот же объект, а `==` сравнивает значения. Поэтому тип камеры сравниваем через `camera["type"] == "top"`, а наличие выбранной камеры проверяем через `camera is not None`.

## Условия

До сих пор мы просто выводили `True` или `False`. Теперь посмотрим, как по результату проверки выбрать, какой код выполнить. Для примера договоримся, что камера готова к записи, если она подключена, её тип — `"front"` или `"top"`, а частота — не ниже 30 кадров в секунду.

```python
camera_type = "top"
camera_connected = True
fps = 30

if not camera_connected:
    print("Камера не подключена")
elif (camera_type == "front" or camera_type == "top") and fps >= 30:
    print("Можно начинать запись")
else:
    print("Проверьте тип камеры и частоту кадров")
```

Сначала Python проверяет условие после `if`. Если камера отключена, выведется первое сообщение. Если она подключена, Python перейдёт к `elif` и проверит тип и частоту. Скобки объединяют две проверки типа камеры, чтобы к их общему результату мы могли добавить проверку частоты через `and`.

`elif` читается как «иначе, если». Таких веток может быть несколько, и Python проверяет их сверху вниз, пока не найдёт первое истинное условие. Если ни одно условие не подошло, выполнится блок `else`, если он есть.

> [!NOTE] Табуляция
> Обратите внимание на отступы перед `print()`. По ним Python понимает, какие строки относятся к каждой ветке. Если после `if` нужно выполнить несколько команд, пишем их с одинаковым отступом. Когда возвращаемся к предыдущему уровню отступа, блок заканчивается. Обычно на каждый уровень добавляют четыре пробела. Во многих редакторах можно настроить клавишу Tab так, чтобы она вставляла пробелы.

## Циклы

В Python есть два вида циклов — `for` и `while`, начнём с `for`. Он пригодится, когда мы хотим перебрать готовый набор элементов или заранее знаем, сколько раз нужно повторить действие. Каждый проход цикла называется *итерацией*.

Вернёмся к списку камер. Чтобы вывести все имена, пройдём по списку циклом `for`.

```python
cameras = ["top", "front"]

for camera in cameras:
    print(camera)
```

```text
top
front
```

На первой итерации в `camera` будет `"top"`, на второй — `"front"`. Если вы допишете ещё одно имя в список, цикл выведет и его. В данном примере `camera` — переменная, которую мы сами так назвали, она перезаписывается циклом на каждой итерации.

А что, если списка у нас нет, а команду нужно выполнить три раза? Тогда можно использовать `range()`. Вызов `range(3)` задаёт последовательность из трёх чисел — `0`, `1` и `2`. Цикл выполнится по одному разу для каждого числа.

```python
for i in range(3):
    print("Проверка", i + 1)
```

```text
Проверка 1
Проверка 2
Проверка 3
```

> [!NOTE] Как работает range()
> Полная запись — `range(start, stop, step)`. `start` задаёт первое число, `stop` — границу, которая в последовательность не входит, а `step` — шаг между соседними числами. Все три аргумента должны быть целыми числами.
>
> Если передать только `stop`, как в `range(3)`, отсчёт начнётся с нуля и пойдёт с шагом `1`. В записи `range(start, stop)` мы сами задаём начало, а шаг по-прежнему равен `1`.
>
> ```python
> print(list(range(1, 6, 2)))   # [1, 3, 5]
> print(list(range(5, 0, -2)))  # [5, 3, 1]
> ```
>
> Здесь `list()` превращает последовательность в список, чтобы мы могли сразу увидеть все числа. Положительный шаг ведёт вперёд, отрицательный — назад. Если шаг равен нулю, Python выдаст ошибку `ValueError`.

Перейдём к `while`. Он пригодится, когда заранее неизвестно, сколько итераций понадобится. Например, мы просим выбрать тип камеры и повторяем вопрос, пока пользователь не введёт `front` или `top`.

```python
camera_types = ["front", "top"]
camera = input("Введите тип камеры: ")

while camera not in camera_types:
    print("Введите front или top")
    camera = input("Введите тип камеры: ")

print("Выбрана камера", camera)
```

> [!NOTE] Ввод с клавиатуры через input()
> `input()` — встроенная функция, с помощью которой программа может попросить пользователя что-нибудь ввести. Например, если мы запишем тип камеры прямо в коде, для выбора другой камеры придётся менять программу. А с `input()` вы можете выбрать камеру прямо во время запуска.
>
> В строке `camera = input("Введите тип камеры: ")` текст в скобках — это подсказка. Python покажет её в консоли и подождёт, пока вы введёте ответ и нажмёте Enter. Если вы введёте `top`, функция вернёт строку `"top"`, которую мы сохраним в переменную `camera`. Дальше цикл проверит, есть ли этот тип в списке.
>
> `input()` всегда возвращает строку, даже если вы ввели число. Например, из введённого `30` получится строка `"30"`. Если с этим значением нужно считать, можем преобразовать его в целое число через `int()`.

Перед каждой итерацией `while` проверяет условие. Если сразу ввести `top`, тело цикла ни разу не выполнится. А если ввести `side`, программа попросит попробовать снова. Как только введённый тип окажется в списке, цикл закончится.

## Функции

Представим, что нам нужно посчитать, сколько кадров запишут две камеры. Первая работает 5 секунд с частотой 30 кадров в секунду, вторая — 10 секунд с частотой 25. В обоих случаях мы умножаем время на частоту кадров.

Если один и тот же блок кода нужен в нескольких местах, его можно вынести в **функцию**. Тогда мы пишем сам расчёт один раз, а дальше вызываем функцию по имени и передаём ей нужные значения. Если расчёт изменится, достаточно будет поправить его в одном месте.

```python
def count_frames(seconds, fps):
    return seconds * fps

top_frames = count_frames(5, 30)
front_frames = count_frames(10, 25)

print(top_frames)    # 150
print(front_frames)  # 250
```

Начинаем с `def`, за ним пишем имя функции и её *параметры* в скобках. Когда вызываем `count_frames(5, 30)`, передаём два *аргумента*. Число `5` попадает в `seconds`, а `30` — в `fps`. При втором вызове те же параметры получат уже `10` и `25`.

Через `return` функция отдаёт результат туда, откуда её вызвали. Например, результат первого вызова мы сохранили в `top_frames`. Если он нужен только для вывода, его можно сразу передать в `print()` — `print(count_frames(5, 30))`.

## Встроенные функции

С двумя встроенными функциями мы уже знакомы — `print()` выводит данные, а `input()` считывает ввод. Ниже собрали ещё несколько полезных функций. Результаты `zip()`, `map()` и `enumerate()` передадим в `list()`, чтобы увидеть все элементы сразу.

| Функция | Что делает | Пример |
| --- | --- | --- |
| `len()` | Возвращает количество элементов. Например, для списка это число его элементов, а для строки — число символов. | `len(["top", "front"])` → `2` |
| `max()` | Возвращает наибольшее из переданных значений. Можно передать несколько значений по отдельности или один список. | `max(15, 25, 30)` → `30` |
| `min()` | Возвращает наименьшее из переданных значений. Как и в `max()`, можно передать отдельные значения или список. | `min(15, 25, 30)` → `15` |
| `any()` | Возвращает `True`, если хотя бы один элемент считается истинным. Для списка из `True` и `False` достаточно одного `True`. | `any([False, True])` → `True` |
| `all()` | Возвращает `True`, если каждый элемент считается истинным. Для списка из `True` и `False` одного `False` достаточно, чтобы получить `False`. | `all([False, True])` → `False` |
| `sum()` | Складывает все числа в переданной последовательности и возвращает их сумму. | `sum([15, 25, 30])` → `70` |
| `zip()` | Объединяет элементы с одинаковыми позициями. Для двух списков получаем пары. Если списки разной длины, перебор заканчивается вместе с коротким. | `list(zip(["top", "front"], [30, 25]))` → `[('top', 30), ('front', 25)]` |
| `map()` | Применяет переданную функцию к каждому элементу по очереди. В примере `str` превращает каждое число в строку. | `list(map(str, [30, 25]))` → `['30', '25']` |
| `enumerate()` | Для каждого элемента выдаёт пару из его номера и значения. По умолчанию нумерация начинается с нуля. | `list(enumerate(["top", "front"]))` → `[(0, 'top'), (1, 'front')]` |
| `sorted()` | Создаёт новый список из переданных элементов и по умолчанию сортирует их по возрастанию. | `sorted([30, 15, 25])` → `[15, 25, 30]` |
| `type()` | Возвращает тип переданного значения. В примере это `int`, потому что `30` — целое число. | `type(30)` → `<class 'int'>` |

## Классы и объекты

Когда мы собирали настройки двух камер в словари, нам пришлось дважды указать, какие поля у них есть. А если мы захотим ещё и выводить настройки каждой камеры одинаково? Можно один раз описать, какие данные есть у камеры и какие действия с ними можно выполнить. Для этого в Python есть **класс**.

Начинаем с `class` и имени класса. Внутри пишем `__init__()` — метод, который Python вызовет после создания нового объекта. В нём запишем начальные настройки камеры.

```python
class CameraSettings:
    def __init__(self, camera_type, fps):
        self.type = camera_type
        self.fps = fps

    def describe(self):
        return f"{self.type}: {self.fps} кадров/с"

    def set_fps(self, fps):
        self.fps = fps

top = CameraSettings("top", 30)
front = CameraSettings("front", 25)

print(top.fps)           # 30
print(front.describe())  # front: 25 кадров/с

top.set_fps(20)
print(top.describe())    # top: 20 кадров/с
print(front.describe())  # front: 25 кадров/с
```

`CameraSettings` — это класс, а `top` и `front` — два **объекта**, или экземпляра этого класса. У каждого свои значения `type` и `fps`. Эти значения хранятся в *атрибутах*. Например, через `top.fps` мы читаем частоту верхней камеры.

`describe()` и `set_fps()` — **методы**. Их объявляем через `def`, как и обычные функции, а вызываем через точку у объекта. Когда пишем `top.set_fps(20)`, Python сам передаёт объект `top` в параметр `self`, а число `20` попадает в параметр `fps`. Поэтому меняется частота именно верхней камеры. Метод `describe()` берёт данные из того объекта, у которого его вызвали. Буква `f` перед строкой позволяет подставить в текст значения выражений из фигурных скобок.

> [!NOTE] Магические методы
> У `__init__()` по два подчёркивания с каждой стороны. Методы с такими специальными именами часто называют *магическими*. Python вызывает их при определённых операциях. Например, `__str__()` задаёт, как объект будет выглядеть в `print()`, `__len__()` определяет результат `len()`, а `__eq__()` позволяет задать своё правило сравнения через `==`.

Помните `is` из блока про логические операции? С его помощью можно проверить, ссылаются ли два имени на один и тот же объект. Создадим две камеры с одинаковыми настройками и сравним их.

```python
camera1 = CameraSettings("top", 30)
camera2 = CameraSettings("top", 30)
same_camera = camera1

print(camera1 is camera2)      # False
print(camera1 is same_camera)  # True
print(camera1.fps == camera2.fps)  # True
```

При каждом вызове `CameraSettings("top", 30)` мы получаем новый объект, даже если значения атрибутов совпадают. А строка `same_camera = camera1` даёт второе имя уже существующему объекту.

## Встроенные методы

У строк, списков и словарей тоже есть готовые методы. Например, чтобы убрать лишние пробелы, вызываем `text.strip()`. Точка здесь работает так же, как в `front.describe()`. Слева пишем объект, а справа — метод, который хотим у него вызвать.

### Строки — str

Методы из этой таблицы возвращают результат, с которым можно работать дальше. Например, после `text = text.strip()` в переменной будет строка без пробелов по краям.

| Метод | Что делает | Пример |
| --- | --- | --- |
| `strip()` | Убирает пробельные символы в начале и конце строки | `"  front  ".strip()` → `"front"` |
| `lower()` | Переводит буквы в нижний регистр | `"FRONT".lower()` → `"front"` |
| `replace()` | Заменяет все вхождения одной части строки на другую | `"front-camera".replace("-", "_")` → `"front_camera"` |
| `split()` | Разбивает строку по разделителю и возвращает список | `"top,front".split(",")` → `["top", "front"]` |
| `startswith()` | Проверяет, начинается ли строка с указанного текста | `"front_camera".startswith("front")` → `True` |

### Списки — list

В каждой строке таблицы начинаем с `cameras = ["top", "front"]`. Методы `append()`, `extend()`, `remove()`, `pop()` и `sort()` меняют сам список.

| Метод | Что делает | Пример |
| --- | --- | --- |
| `append()` | Добавляет один элемент в конец | После `cameras.append("side")` получим `["top", "front", "side"]` |
| `extend()` | Добавляет в конец все элементы другой последовательности | После `cameras.extend(["left", "right"])` получим `["top", "front", "left", "right"]` |
| `remove()` | Удаляет первое вхождение указанного значения | После `cameras.remove("top")` получим `["front"]` |
| `pop()` | Удаляет элемент по индексу и возвращает его. Без индекса берёт последний | `cameras.pop()` вернёт `"front"`, а в списке останется `["top"]` |
| `sort()` | Сортирует список на месте. По умолчанию по возрастанию | После `cameras.sort()` получим `["front", "top"]` |

### Словари — dict

Для примеров возьмём `camera = {"type": "front", "fps": 30}`. Если мы хотим прочитать настройку, которой может не быть, пригодится `get()`. А если нужно перебрать настройки вместе с их именами, берём `items()`.

| Метод      | Что делает                                                                                       | Пример                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| `get()`    | Возвращает значение по ключу. Если ключа нет, вернёт переданное значение по умолчанию или `None` | `camera.get("enabled", False)` → `False`                                  |
| `keys()`   | Даёт доступ ко всем ключам словаря                                                               | `list(camera.keys())` → `["type", "fps"]`                                 |
| `items()`  | Даёт доступ к парам «ключ — значение»                                                            | `list(camera.items())` → `[("type", "front"), ("fps", 30)]`               |
| `update()` | Добавляет новые ключи и заменяет значения существующих                                           | После `camera.update({"fps": 25})` получим `{"type": "front", "fps": 25}` |

## Пакеты

Мы уже написали свою функцию и описали класс. А если нужные функции или классы кто-то уже написал? Их можно подключить к нашей программе и использовать в своём коде.

Обычно связанные функции и классы собирают в **модуль**. Когда кода становится больше, несколько связанных модулей можно объединить в **пакет**. Так инструменты для одной задачи, например для работы с изображениями, доступны под общим именем. 

Обычный пакет можно представить как папку с модулями. В нашем примере `camera_tools` — пакет, а `frames.py` — модуль, в котором лежит функция `count_frames()`.

```text
camera_tools/
├── __init__.py
└── frames.py
```

Файл `__init__.py` показывает Python, что это обычный пакет. Он может быть пустым. Если в нём есть код, Python выполнит его, когда впервые импортирует пакет. Чтобы взять из `frames.py` только нашу функцию, можно написать `from camera_tools.frames import count_frames`. Точка между `camera_tools` и `frames` показывает, что модуль находится внутри пакета.

Часть таких инструментов уже поставляется вместе с Python. Они входят в **стандартную библиотеку**. Например, пакет `json` помогает читать и сохранять данные в формате JSON, а в модуле `math` есть готовые математические функции.

Вернёмся к кадрам. Если запись длится 2,25 секунды при 30 кадрах в секунду, расчёт даст 67,5. Допустим, нам нужно округлить это число вверх до целого. Подключим модуль командой `import math` и вызовем его функцию `ceil()` через точку.

```python
import math

print(math.ceil(2.25 * 30))  # 68
```

Если из модуля нужна только одна функция, её можно импортировать по имени через `from ... import ...`. Тогда вызываем `ceil()` напрямую.

```python
from math import ceil

print(ceil(2.25 * 30))  # 68
```

Для машинного обучения нам встретятся и сторонние пакеты. Например, **PyTorch** подключается через `import torch`, а **TensorFlow** — через `import tensorflow`. В них есть готовые инструменты для вычислений с тензорами, создания и обучения моделей. Такие пакеты нужно установить в рабочее окружение, если их там ещё нет.
