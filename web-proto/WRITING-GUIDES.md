# Как написать статью для вики

Markdown — обычный текст с разметкой. Создай файл `my-guide.md` в папке `guides`, напиши статью и обнови [каталог вики](http://127.0.0.1:4173/#/wiki). Для готовой статической версии порядок публикации описан в [README](./README.md#как-добавлять-статьи).

## Заголовки и текст

Начни файл с `#` и названия статьи. Пустая строка отделяет абзацы. Для разделов используй `##`, для подразделов — `###`. Вики соберёт из них оглавление.

```md
# Первые команды в Linux

Здесь мы научимся открывать терминал и проверять, в какой папке находимся.

## Открываем терминал

1. Запусти приложение **Терминал**.
2. Вводи команду после приглашения оболочки.

### Проверка

Введи `pwd` и посмотри на результат.
```

Две звёздочки с каждой стороны дают **жирный текст**, одна — *курсив*. Имена команд и файлов пиши в обратных кавычках, как `pwd` и `notes.txt`.

Для шагов подойдут `1.`, `2.`, `3.` в начале строк. Для простого списка ставь `-` и пробел перед каждым пунктом.

## Ссылки

В квадратных скобках — текст ссылки, в круглых — её адрес. Для ссылки на другую статью вики достаточно имени её файла.

```md
[Внешний сайт](https://example.org)
[Статья про Linux](linux-101.md)
[Раздел ENV в статье про Linux](linux-101.md#env)
[К разделу «Проверка» в этой статье](#проверка)
```

У простого заголовка `## Проверка подключения` адрес раздела будет `#проверка-подключения`. Для заголовка со знаками препинания открой раздел через оглавление. Возьми из адреса последнюю часть после `/` и вставь её после `#` в ссылке.

## Картинки и подписи

Положи картинку рядом с файлом статьи в `guides`. В начале строки поставь `!`, в квадратных скобках опиши, что на картинке, а в круглых укажи имя файла. Поддерживаются PNG, JPEG, GIF, WebP и AVIF.

```md
![Золотая рыбка смотрит в камеру](fish-meme.webp)

![Золотая рыбка смотрит в камеру](fish-meme.webp "Я ничего не понял. Я рыба.")

![Схема подключения](<Схема подключения.png> "Так выглядит готовое подключение")

![Фото рабочего стола](https://example.org/images/desk.png)
```

Чтобы текст в кавычках появился под картинкой, оставь картинку в отдельном абзаце. Имя файла с пробелами оберни в угловые скобки, как в примере.

Для GitHub Pages и локального запуска фотографии можно сгруппировать по статьям в `guides/data/`. Например, если фото лежит в `guides/data/6so101-assembly/motor.jpg`, укажи в Markdown путь `data/6so101-assembly/motor.jpg`. Этот же формат пути подойдёт для ссылки с превью на оригинал.

## Заметки и предупреждения

Начни заметку со строки `> [!NOTE]`. Каждую следующую строку заметки тоже начинай с `>`. Если внутри нужен новый абзац, оставь между ними строку с одним `>`.

```md
> [!NOTE]
> Команда `pwd` показывает путь к текущей папке.
>
> После перехода в другую папку запусти её ещё раз.
```

| Метка | Когда использовать |
| --- | --- |
| `[!NOTE]` | Пояснение к шагу |
| `[!TIP]` | Короткий совет |
| `[!IMPORTANT]` | Важное условие или обязательный шаг |
| `[!WARNING]` | Предупреждение о последствиях |
| `[!CAUTION]` | Действие, требующее осторожности |

## Команды, вывод и клавиши

Блок кода начинается с трёх обратных кавычек и метки языка. Закрой его отдельной строкой с тремя обратными кавычками.

````md
```bash
pwd
```

```console-output
/home/student
```
````

`bash` подсвечивает команды, а `console-output` оформляет только вывод. Чтобы показать команду и результат в одном блоке `bash`, поставь `$ ` перед командой и оставь вывод на следующих строках.

````md
```bash
$ pwd
/home/student
```
````

Для других примеров есть метки `python`, `dockerfile`, `sh`, `zsh`, `.bashrc` и `man`. Последняя оформляет вывод справки `man`.

Названия клавиш оберни в `<kbd>` и `</kbd>`. Для сочетания пометь каждую клавишу отдельно.

```md
Нажми <kbd>Enter</kbd>.

Чтобы сохранить файл в nano, нажми <kbd>Ctrl</kbd> + <kbd>O</kbd>.
```

## Таблица

Разделяй столбцы вертикальной чертой `|`. Строка с дефисами отделяет шапку таблицы.

```md
| Команда | Что делает |
| --- | --- |
| `pwd` | Показывает текущую папку |
| `ls` | Показывает её содержимое |
```

Перед публикацией открой статью в вики. Проверь, что разделы появились в оглавлении, ссылки ведут куда нужно, картинки загрузились, а команды легко отличить от вывода.
